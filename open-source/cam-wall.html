A live camera wall with an agent that can operate it.

Agentic Cam-Wall turns a small PC and a display into a reliable wall of live security-camera feeds — tiled layouts, named views, rotation, single-camera mode, and stream self-healing that keeps the wall running unwatched. What makes it different is Grace: an agent on the appliance that understands what you want, operates the wall, configures the system, and drives connected surveillance systems. A regular camera wall is passive. This one can act.

A wall that can act.

Ask for the outcome and Grace handles the operational steps. “Solo camera 7.” “Back to the full wall.” “Pull up the loading dock from this morning.” The request can be typed, spoken, or sent by another agent — Grace reasons over it, uses its tools, and operates the wall or your connected systems on your behalf.

The principle is simple: if you can do it with a mouse and keyboard, Grace can do it for you.

What’s on the appliance.

A dependable camera wall, an agent that operates it, and a browser the agent can drive.

The wall

Reliable by default.

Up to 16 live streams in tiled views, with named views, timed rotation, zoom, and single-camera mode. Information bands you author in markdown render as top and bottom overlays. A wedged stream is detected and re-initialized automatically — it works out of the gate and keeps working, unwatched.

Grace

The embedded agent.

An operator that reasons over requests and uses tools, with full GUI/agent parity — anything you can do by hand, Grace can do for you. Operator-editable site knowledge and explicit durable memories. Privileged actions are admin-gated behind a PIN captured out-of-band, announced, and audited.

Browser driving

An agentic NVR operator.

The appliance bundles a visible browser Grace can operate. Bring up your web-based NVR and have Grace search, navigate, review, and display footage through the same UI a person would use — no need to replace the NVR to make it agentic. Credentials are typed host-side only, never into model context.

Ask Grace, any way.

Voice is one way to engage Grace from the room where the wall lives — say the wake phrase (“wake up Grace”) to enter Conversation Mode — but it’s only one path. The same agent answers from the GUI, from keyboard chat, over MCP, or from an external agent system, so a stronger agent like Claude can use Agentic Cam-Wall as a surveillance workstation. Voice is an input; the screen is the output.

A selectable brain.

Grace’s LLM is selectable, and the two brains are never blended. A configured external endpoint — a cloud provider or your own local inference server — runs the full tool-calling loop; a small on-device fallback interprets a closed command vocabulary when no endpoint is reachable, and is structurally denied shell, browser, and destructive tools.

New endpoints go through Stage → Test → Apply: a candidate is tested with a real request before it ever becomes Grace’s active brain, and a failed first use rolls back to last known-good.

Built like an appliance.

Install it and it runs — and keeps running.

  • First-boot install. An idempotent installer takes a stock OS on a small PC to a working appliance; first boot brings up the wall.
  • Kiosk runtime. A compositor and browser lifecycle present the wall fullscreen, with hardware-accelerated decode where available.
  • Self-recovery. A hardware watchdog is armed from boot, so a hard-hung appliance recovers itself.
  • One-click cameras. Auto-discovery over ONVIF and an RTSP sweep, plus NVR-channel or direct-URL sources with per-camera credentials.
  • Closed by default. The appliance binds to loopback until you choose to open the UI and/or MCP to the network — two independent operator switches.

Private by design.

A local appliance, closed to the network by default. Exactly two access controls exist — an optional config password and the admin PIN — and opening a surface adds nothing beyond them. Secrets (camera and NVR credentials, API keys, PINs, WiFi passwords) are captured and used out-of-band: never displayed, never in chat, model context, logs, or transcripts.

No user is identified anywhere in the product, and ambient audio is never retained — the only long-term record is the chat, and it identifies no one.

Who it’s for.

  • Security camera viewing — for managers and security personnel, using industry-standard connectivity, for both security and operational awareness.
  • An agentic surveillance workstation — live cameras in flexible layouts, plus an operator that can act on the wall and drive your NVR for search, playback, review, and display.
  • Common-area feedback — show your team what the camera sees: the loading dock, the front door, the places worth keeping an eye on.

What it isn’t.

Agentic Cam-Wall is not an NVR — it doesn’t record footage, manage retention, or run analytics. It displays live streams and, through Grace, operates your own NVR’s web interface for those functions. It’s environment-agnostic: your network, your cameras, your cloud or local inference — no blessed hardware.

Open source.

Agentic Cam-Wall is MIT-licensed and open source, released at v0.2.1. Install the release on a stock small PC connected to a display; first boot brings up the wall.
